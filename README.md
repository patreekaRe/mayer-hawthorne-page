# Mayer Hawthorne Tribute

A tribute page for Mayer Hawthorne, built for COSW 20.

**Live site:** https://patreekare.github.io/mayer-hawthorne-page/

Plain HTML, CSS and JavaScript with no build step. Open `index.html`, or run `npm start` to serve it locally.

## Photo credits

All photographs are from Wikimedia Commons, resized for the web, and used under their Creative Commons licenses. The full credit list (author, license and source link for each photo) is in the "Photo credits" section at the bottom of the page.
